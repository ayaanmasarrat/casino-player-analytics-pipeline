# Casino Player Analytics Pipeline

A clean-room, end-to-end Python analytics pipeline for casino player data, inspired from a project in my last internship.
Used the assistance of Cursor AI to help implement this project onto GitHub.
Covers feature engineering, behavioural segmentation, and causal inference
(propensity-score matching + difference-in-differences).

> **All numbers and figures in this repository come from a seeded synthetic
> dataset generated by `synth/generate.py`. No real player records, no real
> venue data, no client information of any kind is included.**

---

## Architecture

```
synth/generate.py
      │
      ▼  data/raw/*.csv
casino_analytics/loaders.py
      │
      ▼
casino_analytics/cleaning.py
      │
      ├─▶ features/daily.py
      │       ├─▶ features/demographics.py
      │       ├─▶ features/financials.py
      │       └─▶ features/geo.py
      │                │
      │                ▼
      │         features/player.py  (player rollup + panel)
      │                │
      │         ┌──────┴───────┐
      │         ▼              ▼
      │   segmentation.py   causal/psm.py
      │         │                │
      │   analytics/trends.py  causal/did.py
      │         │                │
      └─────────┴────────────────┘
                      │
                output/ (figures + Excel export)
```

## Modules

| Module | Responsibility |
|---|---|
| `config.py` | Frozen settings: venue coordinates, mileage bands, age buckets, RNG seed |
| `synth/generate.py` | Seeded synthetic data generator (~40k play rows, ~48k player rows) |
| `loaders.py` | `pd.read_csv` with explicit dtype schema, UTF-8-sig safe |
| `cleaning.py` | Deduplicate to one row per `player_id`, parse play dates |
| `features/daily.py` | Merge demographics into play data; aggregate to daily-player level |
| `features/demographics.py` | Exact age at visit; 7 age buckets |
| `features/financials.py` | `theo_hold_pct`, `act_hold_pct`, `no_slot_play_flag` |
| `features/geo.py` | Vectorised haversine distance; Local / Regional / National bands |
| `features/player.py` | Player-level rollup (AMV, ADT); player-month panel |
| `segmentation.py` | Two-level segmentation: L1 value/engagement, L2 days-active |
| `analytics/trends.py` | Monthly active users (MAU) by segment; year-over-year comparison |
| `plots.py` | Chart helpers writing PNGs to `output/figures/` |
| `causal/psm.py` | Propensity score estimation (logistic + StandardScaler); 1:5 caliper matching |
| `causal/did.py` | Difference-in-differences; event-study parallel-trends F-test |
| `cli.py` | `python -m casino_analytics.cli generate` and `run-all` |

## Quick start

```bash
# 1. Install (preferably in a venv)
pip install -e ".[dev]"

# 2. Generate synthetic data
python -m casino_analytics.cli generate

# 3. Run the full pipeline (feature engineering + segmentation + causal + outputs)
python -m casino_analytics.cli run-all

# 4. Open the walkthrough notebook
jupyter notebook notebooks/01_pipeline_walkthrough.ipynb
```

Outputs land in `output/`:
- `output/figures/` — PNG charts (MAU trend, age distribution, propensity overlap, balance plot, event study)
- `output/player_analytics.xlsx` — three-sheet Excel: *daily*, *player*, *panel*

## Tests
